# Metaview

- **URL:** https://www.metaview.ai
- **Category:** AI-native
- **Scraped:** 2026-05-12

## UX/UI Patterns

- Top-level nav is short and outcome-oriented: Platform, Customers, Resources, Pricing, Careers — with a dual auth pattern (Sign in | Book demo | Start free) that splits self-serve from enterprise paths.
- Hero leads with a product-state carousel cycling through four agent surfaces (Sourcing, Application Review, Notes, Reports) so visitors immediately see the product, not just claims about it.
- Page flow: hero carousel -> four agent feature cards -> "Why Metaview" enterprise benefits -> security & AI governance band -> case studies/testimonials -> community/support -> FAQ -> dense footer.
- Distinct desktop and mobile hero variants signal a polished, responsive build instead of a single squished layout.
- Security/governance is given its own marketing section, signaling readiness for enterprise procurement reviews — not buried in the footer.
- FAQ near the bottom doubles as objection-handling for buyers who get cold feet about agentic AI in hiring.

## Visual Design

- Color palette: dark/neutral base (near-black canvas), high-contrast white type, and quiet accent highlights — very little color noise so the product UI screenshots carry the visual weight.
- Abstract orbital/"orb" geometric background elements behind the hero add subtle depth without competing with product screens.
- Typography: large sans-serif H1 with sharp hierarchy down to body; clarity-first, not decorative.
- Hero composition: centered product carousel framed by tight headline + subhead stack, twin CTAs ("Start for free", "Book a demo") immediately under copy.
- Imagery style: actual UI screenshots dominate; no stock photography, no illustrated mascots — the agent IS the hero.
- Density: generous spacing around hero, then tighter card grids for features — breathing room up top, information density below.

## Copy & Messaging

- Hero headline: "Agentic Recruiting Platform"
- Subhead: "AI agents for getting the right people in seat." with supporting line "Metaview is the Agentic Recruiting Platform built for winning talent. Source, engage, and hire better with agents that truly get the brief."
- Primary CTA: "Start for free" (secondary: "Book a demo")
- Value-prop bullets:
  - Finds and outreaches candidates
  - Reviews every inbound application
  - Automatically captures notes
  - Surfaces insights and uncovers evolving trends
- Tone: confident, action-oriented, outcome-focused. Frames AI as a teammate that "gets the brief" rather than a tool — leans on the word "agents" repeatedly to plant category language.

## Takeaways for Hire-Bee

- Lead with a product-state carousel in the hero. Hire-Bee already has differentiated AI surfaces (resume parsing, CV gen, interview scheduling) — cycling through them visually is stronger than a static screenshot and removes the need to describe each feature in prose.
- Adopt a dual-CTA pattern ("Start free" + "Book a demo") to serve both individual seekers/small recruiters and enterprise buyers from the same hero. Maps cleanly onto Hire-Bee's seeker vs recruiter split.
- Pair Hire-Bee's #2a2354 dark purple with abstract orbital/gradient background shapes — Metaview proves that a dark canvas plus subtle geometry lets UI screenshots pop without feeling sterile. This is a natural fit for the existing brand color.
- Promote four crisp "what each agent does" cards verb-first ("Finds and outreaches…", "Reviews every…") — this verb-led pattern reads as capability, not feature list, and would tighten Hire-Bee's current minimal landing copy.
